# 🍔 Online Food Ordering System

## 📌 Project Description

The **Online Food Ordering System** is a Java-based console application that allows customers to view a food menu, select food items, enter quantities, and generate a final bill.

The project demonstrates important Java programming concepts such as classes, objects, ArrayList, loops, conditional statements, methods, and user input.

This project is suitable for students who are learning Java and want to create a simple GitHub portfolio project.

## 🎯 Objectives

* Display an online food menu.
* Allow customers to select food items.
* Accept food quantities.
* Calculate individual item prices.
* Add multiple items to the order.
* Calculate the total bill.
* Apply a discount.
* Display the final order summary.


```bash

```

## ▶️ How to Run in VS Code

### Step 1

Open Visual Studio Code.

### Step 2

Create a folder:

```text
online-food-ordering-java
```

### Step 3

Create:

```text
OnlineFoodOrderingSystem.java
```

### Step 4

Copy the Java program into the file.

### Step 5

Open the VS Code terminal.

Compile the program:

```bash
javac OnlineFoodOrderingSystem.java
```

### Step 6

Run the program:

```bash
java OnlineFoodOrderingSystem
```

## 📝 How to Use

1. Run the application.
2. View the food menu.
3. Enter the food item number.
4. Enter the quantity.
5. The selected item is added to the order.
6. Continue adding items.
7. Select the checkout option.
8. The application calculates the total.
9. A discount is applied when applicable.
10. The final bill is displayed.

## 💰 Discount

The program applies a 10% discount when the order total is ₹500 or more.

Example:

```text
Subtotal = ₹700
Discount = ₹70
Final Total = ₹630
```
